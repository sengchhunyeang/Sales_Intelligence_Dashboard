About the project

An interactive business intelligence dashboard that turns one Excel file of sales into clear, filterable insights.

The project

The goal is to analyze Module5_Sales_Data_2026.xlsx and show what drives sales: which products sell, where, through which channel, to which customers and on which days.

It is a single static website. It needs no server and no database, so it loads fast and can be hosted for free.

How it was built

  1. Read the Sales Data sheet of the Excel file with Python (pandas) and checked that every total equals quantity × unit price.
  2. Embedded the rows in the page as JSON so the site works without a server.
  3. Wrote the charts, filters and table in plain HTML, CSS and JavaScript, with no libraries.
  4. Published the code on GitHub and hosted it on Vercel.
